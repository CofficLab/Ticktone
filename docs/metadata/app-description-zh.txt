Ticktone - 精准节拍器，陪伴每次练习

一款为 macOS 与 iOS 打造的原生精准节拍器。Ticktone 完全在设备本地运行：无需账号、不联网、无统计——只有稳定可靠的节拍声。

核心功能
• 采样级精准引擎——独立音频渲染通路，界面再忙节拍也不漂移
• 速度 30–300 BPM，意大利速度术语标记，点按测速与速度锁定
• 拍号与细分——每小节拍数、拍单位，二 / 三 / 四细分
• 重音模式——每一拍可在弱 / 普通 / 重音 / 静音间循环切换
• 练习工具——预备拍、变速练习（目标速度与步进）、视觉闪烁与触感反馈
• 预设——保存并一键召回完整配置
• 钟摆与拍点指示，跟随你设定的节奏型
• 三种点击音色（经典 / 电子 / 木鱼），音量可调

为什么选择 Ticktone？

许多节拍器在界面繁忙时节拍会漂移，或是把基础练习功能藏在账号与订阅之后。Ticktone 把计时引擎放在独立音频通路上，滚动界面、切换预设、变速练习时，点击声始终稳定。所有功能首次打开即可使用——无需登录、没有广告、不做追踪。

适合人群
• 需要稳定节拍的器乐练习者——钢琴、吉他、小提琴、鼓等
• 按老师布置的速度作业练习的学生
• 用重音与细分讲解节奏型的老师
• 想要一款干净、原生、离线可用的节拍器的任何人
