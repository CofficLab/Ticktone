Ticktone - 精準節拍器，陪伴每次練習

一款為 macOS 與 iOS 打造的原生精準節拍器。Ticktone 完全在裝置本機執行：無需帳號、不連網、無統計——只有穩定可靠的節拍聲。

核心功能
• 取樣級精準引擎——獨立音訊渲染通路，介面再忙節拍也不漂移
• 速度 30–300 BPM，義大利速度術語標記，點按測速與速度鎖定
• 拍號與細分——每小節拍數、拍單位，二 / 三 / 四細分
• 重音模式——每一拍可在弱 / 普通 / 重音 / 靜音間循環切換
• 練習工具——預備拍、變速練習（目標速度與步進）、視覺閃爍與觸感回饋
• 預設——儲存並一鍵召回完整設定
• 鐘擺與拍點指示，跟隨你設定的節奏型
• 三種點擊音色（經典 / 電子 / 木魚），音量可調

為什麼選擇 Ticktone？

許多節拍器在介面繁忙時節拍會漂移，或是把基礎練習功能藏在帳號與訂閱之後。Ticktone 把計時引擎放在獨立音訊通路上，捲動介面、切換預設、變速練習時，點擊聲始終穩定。所有功能首次開啟即可使用——無需登入、沒有廣告、不做追蹤。

適合族群
• 需要穩定節拍的器樂練習者——鋼琴、吉他、小提琴、鼓等
• 按老師指派的速度作業練習的學生
• 用重音與細分講解節奏型的老師
• 想要一款乾淨、原生、離線可用的節拍器的任何人
